# Modelo Instrutor CNH 1 — Guará Agency
Landing page responsiva com identidade própria, inspirada no encadeamento visual e comercial de https://eduaulas.com.br/ . HTML/CSS/JS puros, acessibilidade, FAQ, Google Maps, modalidades de aula e formulário de intenção com WhatsApp parametrizável.

**Prévia:** https://guaraagency-julio.github.io/modelo-instrutor-cnh-1/
**Publicação:** GitHub Actions na branch main; em Settings → Pages, definir **Source = GitHub Actions**.

Os nomes, identidade profissional e cidade são **demonstrativos**. Não há depoimentos, taxas de aprovação, credenciais, histórico profissional ou preços inventados. As duas fotos são ilustrativas com licença CC0, obtidas de PxHere, e não retratam o profissional fictício.
Consulte CONFIGURACAO.md antes de adaptar o projeto para um cliente.
